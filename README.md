# Cheri's Salon Website

A modern and responsive beauty salon website designed to help customers explore salon services, view beauty products, see previous work, read testimonials, and book appointments online.

 Getting Started

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
4. For the live website, deploy the project to a hosting service and add the URL above.

 Project Purpose

This project was created as a frontend web development project to demonstrate a professional salon website with service presentation, product showcase, appointment booking, gallery, testimonials, and contact functionality.
